原型 · 方向 A 暖纸账本

王姐便利店的一天。点中间的 说，选一句示例来模拟说话（原型里没有真实录音）。

建议按这个顺序试

  1. 「卖了三瓶冰红茶」→ 听清了，直接记，底部出「已记」带撤
  2. 「刚才那笔冰红茶是四瓶」→ 直接改，告诉你改了什么
  3. 「今天进了货A二十箱」→ 新货卡，进价黄色空格可先不填
  4. 「卖了两瓶可了」→ 猜测卡，红色空格必须先选
  5. 「卖了五瓶农夫山泉」→ 第一次出现「瓶」，当场问一箱几瓶
  6. 「李婶拿走两条烟…」→ 赊账卡，看欠款怎么变
  7. 「卖两箱昨天进的可乐」→ 指定批次，看不同进价批次怎么算毛利

其他可以点的

  • 流水里任意一笔：看原话、手动改、撤
  • 顶部「待处理」：补进价、补金额、没确认的卡
  • 货品 → 开始盘点：边说边填，再对账
  • 欠款 → 点人：记还款、发对账单
  • 我的：切换记账方式、字号、看说法本
  • 货品 → 可乐：看批次与价格历史；红牛：临期提醒
